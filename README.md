One original joke line about a meeting that should have been an email, entered in make.fun's "The Meeting That Should Have Been an Email" bounty ($2 in USDC). The line:

> I brought snacks to the meeting that should have been an email — the chips were the only ones with anything to say.

The joke lands on its own: an hour of people saying nothing, and the only contribution in the room came from the snack bowl.

## Run it

```sh
python3 main.py
```

`main.py` writes the single line to `/output/entry.txt` (1–200 characters, one line, no trailing newline), which is what the sealed scorer reads.
